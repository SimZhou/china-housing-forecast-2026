# 证据协议

本项目默认房地产研究存在数据口径差异、样本偏差和政策扰动。证据协议的目的，是让每个判断都能追溯、复查和反驳。

## 证据分级

### A 级：可复核原始数据

- 官方或机构发布的可下载数据集。
- 有稳定字段、时间序列、口径说明和更新时间。
- 示例：BIS residential property prices、OECD housing prices、FHFA HPI、国家统计局月度表格。

### B 级：可交叉验证统计口径

- 统计发布、年鉴、公开报告、学术调查数据。
- 可用于趋势判断，但必须与其他来源互证。
- 示例：人口普查、CGSS、CFPS、地方网签、央行社融。

### C 级：研究与解释材料

- 同行评审论文、国际机构研究、行业研究报告。
- 可用于机制解释和变量发现，不能替代数据本身。

### D 级：观点与线索

- 媒体报道、专家访谈、社交平台和搜索趋势。
- 只能生成假设或辅助解释，不能作为核心证据。

## 来源记录要求

每个来源至少记录：

- 来源名称和发布机构。
- 国家、地区或城市覆盖范围。
- 指标定义、统计口径和频率。
- 时间跨度、获取方式和访问限制。
- 可信度评级、偏差风险和下一步处理动作。

## 偏差处理

- 官方数据：记录政治激励、统计口径变化、样本代表性和修订风险。
- 平台数据：记录平台覆盖、挂牌与成交差异、反爬限制和商业筛选。
- 调查数据：记录抽样范围、题项变更、缺失值和跨国可比性。
- 国际数据：记录制度差异，尤其是土地制度、税制、信贷和租赁市场差异。
- 购买或二次整理数据：记录购买渠道、卖家描述、原始来源声明、缺失值、单位换算、插值或预测填补方法；不能因为“整理完整”就默认真实。

## 购买数据使用规则

- 原始购买数据不提交到 Git，不公开共享，只保留目录说明文件。
- 购买数据可作为相对可信候选来源，但必须与公开年鉴、地方统计局、平台数据或国际数据库交叉验证。
- 含线性插值、ARIMA 填补或其他预测补全的数据，必须区分原始观测和填补值。
- 任何基于购买数据得到的结论，都要写明该数据的来源限制和可能偏差。

## 反证要求

任何关键判断都要检查至少一种相反解释：

- 价格下跌可能来自人口收缩，也可能来自信用收缩、库存压力或预期转弱。
- 成交回暖可能是真需求恢复，也可能是政策补贴、价格下调或集中释放。
- 婚育观念变化可能影响购房需求，也可能被收入、房价和就业压力共同驱动。
- 国际类比必须说明相似变量和不同约束，不能只引用结果。

## 输出规范

- 报告中的判断使用“数据支持”“初步迹象”“待验证假设”三类强度。
- 未完成交叉验证的内容不得写成结论。
- 涉及预测时，必须写明适用城市层级、时间窗口和主要失败条件。
