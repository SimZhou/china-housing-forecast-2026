# 城市层级框架

本项目不使用单一全国均值直接推断中国房价。第一阶段采用城市层级框架，后续再根据数据可得性细分到具体城市。

## 第一版层级

### 一线城市

北京、上海、广州、深圳。

关注点：

- 全国资源吸附能力和高收入就业。
- 土地稀缺、教育医疗资源和政策限制。
- 二手房市场比新房更能反映真实压力。

### 新一线与强二线城市

典型城市包括杭州、南京、苏州、成都、武汉、西安、合肥、长沙、重庆、天津等。具体名单后续按数据来源固定。

关注点：

- 人口流入和产业升级是否能支撑高估值。
- 新区供应、库存和土地财政依赖。
- 高学历就业、互联网和制造业周期影响。

### 普通二线城市

省会、计划单列市和区域中心城市中，人口吸附与产业增长较弱的一组。

关注点：

- 本地收入能否消化库存。
- 政策放松对成交和价格的边际效果。
- 新房和二手房价格分化。

### 三四线城市

多数地级市、县级市和都市圈外围城市。

关注点：

- 人口流出、老龄化和家庭户收缩。
- 棚改货币化退潮后的需求缺口。
- 库存、交付、地方财政和房企风险。

### 资源型与收缩型城市

不完全按行政层级归类，单独标记。

关注点：

- 产业单一、人口净流出、财政约束。
- 房价流动性不足导致指数失真。
- 成交量比价格更重要。

## 层级变量

每个城市层级至少跟踪：

- 人口：常住人口、出生、婚姻、家庭户。
- 产业：就业、工资、招聘、财政收入。
- 住房：新房、二手房、租金、库存、土地。
- 金融：按揭、居民贷款、地方债务。
- 社会文化：婚育观念、家庭责任、独居和生活方式变化。

## 城市内部地段

城市层级只能解释城市之间的差异，不能直接判断一套房是否值得购买。对具体房产下判断时，必须继续拆分到城市内部地段。

### 核心地段

特征：

- 靠近高收入就业中心或稳定公共部门就业中心。
- 轨交、教育、医疗、商业和公共服务可达性强。
- 二手房成交活跃，同质房源可比样本较多。
- 租赁需求稳定，租金对房价有一定约束。

### 次核心地段

特征：

- 通勤和公共服务可接受，但依赖特定产业、新区兑现或配套建设。
- 成交活跃度弱于核心地段，价格更受政策和供给影响。
- 改善需求和刚需需求可能并存，需要区分户型和楼龄。

### 非核心地段

特征：

- 远郊、新区、产业兑现弱、库存高或公共服务薄弱。
- 挂牌价格可能失真，成交量和成交周期比挂牌价更重要。
- 对人口流入、信贷放松和地方托市政策更敏感。

## 使用规则

- 全国结论必须拆分到城市层级重新检查。
- 城市层级不是固定事实，后续可以根据人口、产业和库存数据重分类。
- 对具体城市下判断时，要说明该城市属于哪个层级，以及为什么。
- 对单套房下判断时，要同时说明城市层级、地段层级、房屋属性和成交流动性。

## 第一版种子表

`data/city-tier-seed-v1.csv` 是第一版城市层级种子表，由 `src/build_city_tier_seed.py` 从 `data/city-registry.csv` 生成。

当前覆盖 298 个城市：

- 一线：4 个。
- 新一线与强二线：15 个。
- 普通二线：52 个。
- 三四线：227 个。
- 资源型或收缩型候选：20 个，作为特殊标记独立于主层级。

这张表只用于让后续分析可以先按城市层级切片。它不是最终结论，不能直接用于投资判断。下一版应至少接入人口、产业、收入、库存、成交、租金和地段数据后重新校正。

## 第一版细分表

`data/city-segment-seed-v1.csv` 是第一版城市细分种子表，由 `src/build_city_segment_seed.py` 从 `data/city-tier-seed-v1.csv` 生成。

当前覆盖 298 个城市：

- 一线核心城市：4 个。
- 新一线与强二线核心城市：15 个。
- 普通二线与区域中心城市：52 个。
- 历史区划或数据异常城市：4 个。
- 资源型或收缩型候选城市：20 个。
- 都市圈外围承接型候选城市：38 个。
- 普通三四线城市：165 个。

这张表的主要作用是避免把所有三四线城市混为一组。历史区划或数据异常城市不应直接进入趋势均值；资源型或收缩型候选、都市圈外围承接型候选也必须用人口、产业、通勤、库存、成交和租金数据校正。
