# 候选数据源

此清单只记录候选来源，不代表已经验证可靠。

## 中国房价与交易

- 国家统计局：70 个大中城市住宅销售价格指数。
- 地方住建部门：新房、二手房网签数据。
- 贝壳、安居客、房天下等平台：挂牌价、挂牌量、成交周期。
- 冰山数据：二手房成交价、房价走势、成交量、挂牌量、去化周期、新房成交量等；属于交互页面和会员功能混合来源，需先验证公开字段、付费限制和自动化采集合规性。
- 中指研究院、克而瑞等机构：土地、库存、房企销售口径。

## 人口与迁徙

- 国家统计局和历年统计年鉴：出生人口、常住人口、城镇化率。
- 公安、民政、教育等间接数据：户籍、婚姻、入学人口。
- 百度迁徙、高德、腾讯位置服务等高频迁徙数据。

## 社会文化与家庭观念

- World Values Survey、European Values Study、Asian Barometer 等跨国价值观调查。
- 中国综合社会调查、家庭追踪调查、劳动力动态调查等国内微观调查。
- 民政、人口普查、抽样调查：结婚、离婚、独居、家庭户规模、代际同住。
- 学术论文：婚育观念、代际支持、住房财富、家庭主义、个人主义和消费偏好的变化。
- 搜索指数与社交平台公开趋势：只用于发现假设，不能单独作为核心证据。

## 就业、收入与消费

- 人社、统计年鉴、招聘平台：就业、工资、岗位需求。
- 居民收入、消费、CPI、PPI、社融和居民贷款。

## 土地与财政

- 自然资源部门土地成交公告。
- 地方财政收入、土地出让收入、城投债和地方债。

## 国际比较

- BIS Residential Property Price Statistics。
- OECD housing prices and affordability indicators。
- FRED、FHFA、Case-Shiller 等美国房地产数据。
- 日本国土交通省、韩国统计厅、欧盟 Eurostat。
- 各国人口、婚育、家庭结构和价值观调查数据，用于比较社会文化因素与房地产周期的关系。

## 待验证问题

- 各平台挂牌数据的反爬限制、覆盖城市和历史可得性。
- 冰山数据等交互式商业页面是否存在稳定公开接口，是否允许自动化采集，以及未付费账号能否获得足够历史数据。
- 网签数据是否有稳定接口或可归档页面。
- 同一城市新房、二手房、租金、土地数据是否能统一到月度频率。
- 国际数据是否能映射到中国城市层级，而不是只做国家均值比较。
- 社会文化变量与房价之间可能存在长滞后和共同因果，需要避免把相关性直接解释为因果。
